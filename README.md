# Cloud Security Threat Detection System

## About the Project
This project uses Python to identify suspicious cloud login activities by calculating risk scores.

## Objectives
- Detect suspicious login activities.
- Calculate risk scores.
- Classify risks as LOW, MEDIUM, or HIGH.
- Recommend security actions.

## Technologies Used
- Python
- HTML
- GitHub

## How It Works
The system checks login location, login time, and failed login attempts to calculate risk scores and identify suspicious activities.

This project demonstrates basic cloud security and suspicious login detection using Python.
